# 🌿 LowCostEcology — Open Resources

> A curated list of free or low-cost databases, software, and images for ecological research. Companion resource to the paper **"Ecology on a budget"**.

🌐 **Website:** `https://agostinatorresm.github.io/LowCostEcology`

---

## How to suggest a resource

1. Visit the website and click **"Suggest a resource"**
2. Fill in the Google Form
3. The team will review your submission before adding it to the database

## How to report a problem or give feedback

1. Visit the website and click **"Feedback, problems or improvements?"**
2. Fill in the Google Form
   
## Project structure

```
LowCostEcology/
├── index.html # Main website (data loaded live from Google Sheets)
├── MC.jpg # Project lead photo
└── README.md
```

## Data

Resources are managed in a Google Sheets database. Approved community suggestions are added directly to the sheet and appear on the website automatically.
